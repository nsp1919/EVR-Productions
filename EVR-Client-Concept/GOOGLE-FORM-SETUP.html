Your EVR Google Form setup

This creates a shorter, two-section Google Form in your account. Fill business details, read the content list, then paste one Drive folder link. The form remains an unpublished draft until you review and publish it.

Updating from the long form: replace all code in your existing Apps Script project with the revised script, save and run createEvrClientForm again. Version 2 creates a NEW short form and prints its new links. The old form and its responses are left untouched. Publish and share the new responder link instead of the old one.

Download the ready-to-run Apps Script

Setup steps

  1. Sign into the Google account that should own the form. Open Google Apps Script and choose New project.
  2. Name the project EVR Client Content Form.
  3. Open the downloaded CREATE-EVR-GOOGLE-FORM.gs in VS Code or a text editor. Copy all its contents.
  4. In Apps Script, replace the default contents of Code.gs with the copied script. Save.
  5. Select createEvrClientForm from the function dropdown, then click Run.
  6. Review Google's authorisation request and approve only if you are comfortable granting your own script Google Forms access. Do not send anyone your password or OTP. If your organisation blocks authorisation, ask the account administrator rather than trying to bypass the restriction.
  7. After execution completes, open the Execution log. It contains an EDIT LINK and a RESPONDER LINK.
  8. Open the EDIT LINK privately. Check the two sections, use Preview and choose the appearance you want. No logo is uploaded automatically.
  9. Click Publish and check responder access. Restrict access to your client where supported, or choose an appropriate link-access setting. Workspace rules may limit external access.
  10. Copy the responder link and send that to the client. Do not send the edit link. Test the published link using the intended client access conditions before sending.

Included sections

  1. Business details: 13 fields for business name, tagline, WhatsApp, email, address, Maps, timings, locations, Instagram, YouTube and short business/service descriptions.
  2. Content list + one Drive link: read-only instructions list all 60 photos by category and orientation, the 12 videos and durations, logo, six project stories, 4-6 reviews and optional 2-4 video testimonials. This section has just ONE answer field: the main Google Drive folder link.

No pricing questions. The form states: "Pricing will be discussed on a call." It uses only the requested content categories, without adding domain, hosting, legal-policy or payment questions.

How media collection works

No readiness grids, individual upload links, project-by-project answers or quote-option selection tables. Clients put all content in one Drive folder, optionally organised into subfolders, and paste one link at the end. They can add missing files to that same folder later. Quote-form choices can be discussed on a call. The script does not upload files or change folder permissions.

Keep client media private. The client should grant the developer access directly to the supplied folders, without making them public. Submitting a folder URL does not automatically grant permission or copy its contents.

Responses and privacy

Responses are saved by Google Forms in the owner's account. Use the Responses tab to read them. Linking a Google Sheet and enabling owner notifications are optional manual settings. Response summaries are not public. Respondents can edit their response using their edit-response link.

The script does not force one response per signed-in user or collect account emails automatically. It asks explicitly for the business email address. Your account's responder-access policies still apply.

If you run the script again

The first run of version 2 creates the short form even when version 1 was already run in the same project. Further runs return the existing short form's links, without duplicate questions, deleted responses or overwritten edits. If setup fails partway, it stops with the partial draft's link. Do not publish the incomplete draft. To start fresh without deleting anything, use a new Apps Script project.

If you delete the form or lose access, the script will report Google's error instead of silently creating a replacement. Use a new project when you intentionally want another form.
